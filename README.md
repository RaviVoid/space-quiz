# 우주 탐험 퀴즈

우주와 천문학 지식을 확인하는 가벼운 웹 퀴즈입니다. 열 가지 질문에 답하며 점수를 얻고, 진행 상황과 결과를 확인할 수 있습니다. 최고 점수는 브라우저에 저장됩니다.

## 로컬에서 실행하기

별도의 빌드 도구나 의존성은 필요하지 않습니다.

1. 이 저장소를 내려받거나 복제합니다.
2. `index.html` 파일을 웹 브라우저에서 엽니다.

## GitHub Pages 배포

`main` 브랜치에 변경 사항을 푸시하면 `.github/workflows/deploy-pages.yml` 워크플로가 `index.html`을 GitHub Pages에 배포합니다. GitHub 저장소 설정에서 Pages의 빌드 및 배포 소스로 **GitHub Actions**를 선택해야 합니다.
